# Задачник

Простое учебное веб-приложение для телефона и компьютера. Каждый пользователь видит свои задачи. К задаче можно добавить заметку и дату. Календарь группирует задачи по датам, статистика показывает выполнение, а фокус-таймер отсчитывает 25 минут.

## Запуск

Нужен Node.js 24 или новее. Устанавливать пакеты не нужно.

```sh
node --watch server.mjs
```

На компьютере откройте [http://localhost:3000](http://localhost:3000). Для проверки с телефона подключите оба устройства к одной сети Wi-Fi и откройте на телефоне адрес компьютера в этой сети с портом 3000.

## Что показать на проверке

1. Зарегистрироваться, выйти и войти снова.
2. **Create** — добавить задачу.
3. **Read** — увидеть задачу в списке после обновления страницы.
4. **Update** — изменить название, заметку или дату и отметить задачу выполненной.
5. **Delete** — удалить задачу.

`server.mjs` обрабатывает формы, проверяет вход и работает с SQLite. `style.css` задаёт оформление. Файл базы `tasks.db` создаётся при первом запуске. Сервер хранит хеши паролей, а в браузере хранится идентификатор сессии.
